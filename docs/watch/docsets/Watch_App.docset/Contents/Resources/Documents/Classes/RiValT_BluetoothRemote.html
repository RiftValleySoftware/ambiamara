RiValT_BluetoothRemote

final class RiValT_BluetoothRemote : NSObject, ObservableObject
extension RiValT_BluetoothRemote: CBCentralManagerDelegate, CBPeripheralDelegate

A foreground iPad can vend the same request/reply protocol as the paired phone. GATT indications carry replies and change hints; each request is applied only by the host.
