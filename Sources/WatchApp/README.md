# RVT Remote

The Watch app displays and controls the timer on a paired iPhone or nearby iPad. WatchConnectivity carries requests to the iPhone. The Bluetooth transport discovers an iPad, confirms pairing, and exchanges timer requests and replies.

The selected host runs the timer and advances its group. The Watch uses the host’s countdown deadline to display the remaining time and sends actions against the state the wearer saw.
